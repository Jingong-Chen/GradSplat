# re10k_rock

Six input frames of the RealEstate10K test scene `64fe38ce3160d0fb`, the first row of Figure 4 (narrow protocol), with the frame numbers 0, 7, 10, 13, 19, 27 of the evaluation index `re10k_narrow_volsplat.json`. The images are the frames of the test set as distributed by pixelSplat, unchanged; `cameras.json` holds the camera of each frame (camera-to-world, OpenCV axes, and the pixel intrinsics of the image).

RealEstate10K: Zhou et al., *Stereo Magnification: Learning View Synthesis using Multiplane Images*, SIGGRAPH 2018, https://google.github.io/realestate10k/. Its camera data is licensed by Google LLC under a Creative Commons Attribution 4.0 International License. The frames come from the YouTube videos that the dataset lists and are included here only as examples for noncommercial research.
